# Fiesta Food Ordering App

A Python command-line application developed for my Programming I coursework at the University of Texas at San Antonio (UTSA).

## Project Overview
This application simulates a food ordering system for San Antonio's Fiesta celebration. Users select a menu item, enter a quantity, and receive an itemized receipt that includes subtotal, sales tax, and total cost.

## Technologies
- Python 3
- Command-line interface (CLI)
- Conditional statements and functions
- Formatted string output

## Features
- Displays five Fiesta food and beverage options
- Accepts user menu selections and quantities
- Calculates subtotal and 8.75% sales tax
- Generates formatted purchase receipts
- Includes conditional messages based on customer orders

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project directory.
4. Run the following command:

`python lab01.py`

## Program Workflow
1. Display the food menu.
2. Ask the user to select an item.
3. Request the quantity.
4. Calculate subtotal, tax, and total.
5. Display the receipt.

## Current Limitations
- Non-numeric input can cause an error.
- Negative quantities are not rejected.
- Invalid menu selections default to Agua Fresca.

## Future Improvements
- Add input validation and error handling.
- Support multiple items in one order.
- Allow users to review and modify their orders.
- Add automated tests for calculations.
